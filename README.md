# LEXMORE COMMERCE APEX

Premium black/gold 3D-inspired e-commerce template.

## Included
- Home
- Shop with search + category filter
- Product detail
- Cart with localStorage
- Checkout flow
- Customer login demo
- Orders
- Admin dashboard
- Responsive mobile layouts
- Premium LEXMORE visual system
- Hero artwork in `assets/lexmore-hero.webp` (compressed)

## Production upgrades
This is a front-end commercial template/demo. For a real client or SaaS product, connect:
- Stripe/PayPal or a local payment gateway
- Real authentication
- Database + product CMS
- Order/POS management
- WhatsApp Business number
- Shipping provider
- Analytics
- SEO metadata / sitemap
- Real 3D GLB models or optimized product renders
